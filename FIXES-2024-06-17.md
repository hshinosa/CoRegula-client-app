## 2. Perbaikan Modal Focus Loss Issue

**File:** `resources/js/components/ui/BaseModal.tsx`

### Masalah
Ketika user mengetik di text field dalam modal, fokus hilang setelah 1 karakter karena `AnimatePresence` dari framer-motion menyebabkan re-render yang berlebihan.

### Perbaikan
Menghapus `AnimatePresence` dan stabilisasi reference onClose menggunakan `useRef`:

```tsx
// SEBELUM (Line 1)
import { AnimatePresence, motion } from 'framer-motion';

// SESUDAH
import { motion } from 'framer-motion';

// Tambah useRef untuk stabilize onClose
const onCloseRef = useRef(onClose);

useEffect(() => {
  onCloseRef.current = onClose;
}, [onClose]);

// Update useEffect dependency array
useEffect(() => {
  // ... kode existing
}, [open, closeOnEsc]); // Hapus onClose dari dependency
```

### Dampak
✅ Fokus input tidak hilang saat mengetik
✅ Modal tetap responsif tanpa re-render berlebihan
✅ Animasi tetap smooth dengan motion.div

## 3. Perbaikan Group Controller Timeout

**File:** `app/Http/Controllers/GroupController.php`

### Masalah
Operation create group dan assign members stuck/hang di VPS karena timeout terlalu singkat (10s default).

### Perbaikan
Menambahkan timing measurement dan meningkatkan timeout untuk operasi group:

#### a. Method `store()` (Create Group)
```php
public function store(Request $request, string $course)
{
    // ... validasi
    
    $startTime = microtime(true);
    
    try {
        // Tingkatkan timeout dari 10s ke 30s
        $response = $this->apiRequest(timeout: 30, connectTimeout: 10)
            ->post($this->apiUrl() . "/api/courses/{$course}/groups", [
                'name' => $validated['name'],
            ]);
        
        $duration = round((microtime(true) - $startTime) * 1000, 2);
        Log::info('Group creation completed', [
            'course_id' => $course,
            'duration_ms' => $duration
        ]);
        
        // ... response handling
    } catch (ConnectionException | RequestException $e) {
        $duration = round((microtime(true) - $startTime) * 1000, 2);
        Log::error('Failed to create group', [
            'course_id' => $course,
            'duration_ms' => $duration,
            'error' => $e->getMessage()
        ]);
        return back()->withErrors(['error' => 'Failed to create group']);
    }
}
```

#### b. Method `addMembers()` (Assign Members)
```php
public function addMembers(Request $request, string $course, string $group)
{
    // ... validasi
    
    $startTime = microtime(true);
    
    try {

            ->post($this->apiUrl() . "/api/courses/{$course}/groups/{$group}/members", [
                'member_ids' => $validated['member_ids']

        Log::info('Add members completed', [
            'course_id' => $course,

        ]);
        
        // ... response handling
    } catch (ConnectionException | RequestException $e) {
        $duration = round((microtime(true) - $startTime) * 1000, 2);
        Log::error('Failed to add members', [
            'course_id' => $course,
            'group_id' => $group,
            'duration_ms' => $duration,
            'error' => $e->getMessage()
        ]);
        return back()->withErrors(['error' => 'Failed to add members']);
    }
}
```

### Dampak
✅ Operasi group tidak lagi stuck/hang
✅ Timeout meningkat ke 30s untuk operasi berat
✅ Logging duration untuk monitoring performa
✅ Error handling lebih baik

## 5. Perbaikan UnifiedMaterialsTab

**File:** `resources/js/components/lecturer/UnifiedMaterialsTab.tsx`

### Masalah
Upload material tidak memberikan feedback yang jelas saat terjadi error.

### Perbaikan
Menambahkan error handling dan toast notification:

```tsx
// Upload handler dengan error handling
const handleUpload = async (file: File) => {
  try {
    const formData = new FormData();
    formData.append('file', file);
    
    const response = await fetch('/api/materials/upload', {
      method: 'POST',
      body: formData,
    });
    
    if (!response.ok) {
      throw new Error('Upload failed');
    }
    
    toast.success('Material berhasil diupload');
    // ... refresh data
  } catch (error) {
    toast.error('Gagal mengupload material');
    console.error('Upload error:', error);
  }
};
```

### Dampak
✅ User mendapat feedback jelas saat upload berhasil/gagal
